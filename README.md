# Moca 🐱📚

**Moca** is an Android-based English learning and pronunciation practice application designed for high school students. It helps learners improve their English vocabulary, reading skills, and pronunciation through interactive exercises and engaging learning activities.

### Features
- **Word Practice** – Learn English vocabulary with definitions, pronunciations, and example sentences.
- **Sentence Practice** – Improve reading and pronunciation through sentences at different difficulty levels.
- **High School Level** – Practice more challenging sentences with advanced vocabulary and complex sentence structures.
- **Daily Challenge** – Complete daily learning activities and earn rewards.
- **Speech Recognition** – Practice speaking and receive feedback based on recognized speech.
- **Text-to-Speech** – Listen to correct word and sentence pronunciations.
- **Reading Speed Controls** – Customize playback speed to match your learning pace.
- **My Progress** – Monitor learning activities, scores, points, and practice history.
- **Settings** – Customize sound and speech preferences.
- **Cat-Themed Interface** – Enjoy a friendly and engaging learning environment.

### Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Android Text-to-Speech (TTS)
- Android Speech Recognition

### Project Purpose
Moca aims to make English learning more accessible, interactive, and enjoyable by providing students with opportunities to practice vocabulary, reading, and pronunciation anytime using an Android device.
